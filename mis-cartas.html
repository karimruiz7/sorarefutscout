Tablero Divination · seis niveles

Recreación funcional basada en el tablero compartido del Set Divination (noviembre de 2026). Los objetivos y premios se muestran como referencia. Cada Set futuro puede tener otras reglas y premios; no se leen automáticamente el nivel, las vidas ni el resultado de la cuenta Sorare.

Para Divination se ilustra el capitán (+50 % sobre su media). La edición ahora puede identificarse, pero no se calculan aún su bonus real, partidos puntuables ni restricciones de cada nivel. La puntuación real puede diferir mucho. Nunca se envían alineaciones a Sorare.

El Set y la edición indicados proceden de la API. Pendiente: elegibilidad por tablero y nivel, reglas de partidos, bonus y cartas ya usadas. No se envían alineaciones a Sorare.

Pro · candidatos por Game Week y rareza

Se comprueba el próximo partido SO5 devuelto por Sorare para futbolistas con alguna carta Limited, Rare, Super Rare o Unique. No es una comprobación de inscripción, titularidad o de elegibilidad real. Un jugador sin partido como próximo encuentro no necesariamente carece de partido en Game Weeks posteriores.
